# Adwaita icons

This directory contains the subset of Adwaita Icon Theme 3.38.0 used by
cloud.nimbus. The assets were copied without modification from the official
GNOME release archive:

https://download.gnome.org/sources/adwaita-icon-theme/3.38/

Artwork attribution: GNOME Project — https://www.gnome.org/

The original dual-license notice is preserved in `COPYING`: GNU LGPL v3 or
Creative Commons Attribution-ShareAlike 3.0 United States.

Files are renamed to product-facing semantic names so templates do not depend
on the source theme's directory structure. Full-color folder and MIME icons
come from the corresponding `Adwaita/512x512` directories; UI controls are the
corresponding Adwaita symbolic SVG assets.

`upload.svg` is the upstream `go-up-symbolic.svg`; `remote-folder.svg` is the
upstream `folder-remote-symbolic.svg`.
